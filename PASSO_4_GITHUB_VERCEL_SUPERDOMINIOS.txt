ETAPA 4D: CONECTAR SEU DOMINIO sigmavertice.org NA VERCEL
================================================================================

1) No DASHBOARD DA VERCEL do projeto sigmavertice:
   → Clique no menu superior: Settings
   → Clique no menu esquerdo: Domains
   → Digite: sigmavertice.org → clique no botão [Add]
   → Digite também: www.sigmavertice.org → clique no botão [Add]

2) A Vercel vai mostrar para cada domínio o STATUS "Invalid Configuration" (normal),
   e ao lado o valor do registro DNS que VOCÊ PRECISA COLOCAR na SuperDomínios.

   Para o domínio sigmavertice.org (sem o www):
   → Vercel vai mostrar algo tipo:
     Type: A
     Name: @
     Value: 76.76.21.21    (ou outro IP, use O QUE APARECER NA SUA TELA)

   Para o domínio www.sigmavertice.org (com www):
   → Vercel vai mostrar algo tipo:
     Type: CNAME
     Name: www
     Value: cname.vercel-dns.com   (ou um tipo: vercel-dns.com, use o que está na sua tela)

   ANOTE ESSES VALORES num bloco de notas temporario, VOCÊ VAI USAR AGORA.

================================================================================
ETAPA 4E: PAINEL SUPERDOMINIOS · DNS → APONTAR PARA VERCEL
================================================================================

1) Abra https://superdominios.com.br e faça login com sua conta.

2) No painel do SuperDomínios, clique em "Meus produtos" ou "Gerenciar hospedagens"
   até chegar na tela do domínio sigmavertice.org.
   (É a mesma tela que você me mostrou no print, onde tem "Gerenciamento de DNS".)

3) No menu ESQUERDO, clique em → Gerenciamento de DNS

4) Você vai ver a LISTA DE REGISTROS DNS existentes.

   PRIMEIRO: APAGUE registros ANTIGOS do tipo A e CNAME de @ e www,
   se houver algum (pois eles apontavam para a hospedagem antiga).
   Para apagar: no final de cada linha tem um ícone lixeira / excluir.
   Apague APENAS os registros A (Name=@) e CNAME (Name=www).
   Não apague registros de tipo MX (email), NS, TXT etc.

5) DEPOIS, CLIQUE NO BOTÃO [Adicionar Registro] (ou equivalente):

   PRIMEIRO REGISTRO (para o domínio principal):
   Tipo:             A
   Nome (Host):      @     (ou deixe em branco, se o painel aceitar)
   Valor (Destino):  (cole o IP que a VERCEL mostrou, exemplo 76.76.21.21
                      → USE O VALOR EXATO QUE ESTÁ NA SUA TELA DA VERCEL, nao use o exemplo)
   TTL:              300 (ou deixe o padrão Automatic / 1 hora = 3600, tanto faz)
   Clique em [Salvar Registro].

   SEGUNDO REGISTRO (para o www):
   Tipo:             CNAME
   Nome (Host):      www
   Valor (Destino):  (cole o valor CNAME da Vercel, exemplo: cname.vercel-dns.com
                      → USE O QUE APARECE NA SUA TELA DA VERCEL, use exatamente)
   Clique em [Salvar Registro].

6) Salve tudo.
