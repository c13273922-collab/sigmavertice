PARTE 1/5 — CRIAR CONTA E IMPORTAR PROJETO NA VERCEL (grátis)
======================================================================

1. Abra: https://vercel.com/signup
2. Clique em "Continue with GitHub" (ou GitLab/Bitbucket — qualquer um serve).
   - Se não tiver GitHub, é rápido criar uma conta gratuita em github.com.
3. No painel da Vercel, clique no botão "Add New..." → "Project".
4. Clique em "Continue with GitHub" e autorize a Vercel a ler seus repositórios.
5. Dê "Import" do repositório "sigmavertice" que você vai criar/enviar.
   --- SE VOCÊ AINDA NÃO TEM O PROJETO NO GITHUB (FAÇA ISSO ANTES) ---
   a) Abra PowerShell na pasta d:\0001\sigmavertice e rode (um por vez):
        git init
        git add .
        git commit -m "Primeiro deploy Sigma Vertice"
        git branch -M main
        git remote add origin https://github.com/SEU-USUARIO/sigmavertice.git
        git push -u origin main
   (Você precisa criar o repositório vazio "sigmavertice" lá no github.com/new primeiro)
   -----------------------------------------------------------------
6. Na tela "Configure Project":
   - FRAMEWORK PRESET: a Vercel detecta NEXT.JS automaticamente — deixe como está.
   - ROOT DIRECTORY: deixe "./" (raiz).
   - BUILD COMMAND: deixe "next build" (automático).
   - OUTPUT DIRECTORY: deixe ".next" (automático).
   - INSTALL COMMAND: deixe automático.
7. ABAIXO, na seção "Environment Variables" — ANTES DE CLICAR EM DEPLOY —
   cole as 3 variáveis do Supabase (veja PARTE 2 abaixo).


======================================================================
PARTE 2/5 — COLOCAR AS VARIÁVEIS DE AMBIENTE NA VERCEL (SUPABASE)
======================================================================

Localize as chaves reais do seu Supabase em:
   https://supabase.com/dashboard/project/swpoqlgsyfecpdwyjffv/settings/api

Copie exatamente estes 3 nomes e COLE na área Environment Variables da Vercel
(ambiente Production + Preview + Development — marque os 3):

1)  NAME:   NEXT_PUBLIC_SUPABASE_URL
    VALUE:  https://swpoqlgsyfecpdwyjffv.supabase.co

2)  NAME:   NEXT_PUBLIC_SUPABASE_ANON_KEY
    VALUE:  (Cole aqui a "anon public" key do Supabase — a PÚBLICA)

3)  NAME:   SUPABASE_SERVICE_ROLE_KEY
    VALUE:  (Cole aqui a "service_role" key do Supabase — a PRIVADA, NÃO EXPOR NO CLIENTE)

Depois clique em "Deploy".
Aguarde 2–5 minutos. A Vercel vai dar build, instalar dependências e subir.
No final, você terá uma URL tipo:  https://sigmavertice-xxxx.vercel.app
Abra essa URL e confira se o portal carrega (ainda com domínio temporário).


======================================================================
PARTE 3/5 — CONFIGURAR SEU DOMÍNIO sigmavertice.org NA VERCEL
======================================================================

1. No painel da Vercel, abra o projeto Sigma Vértice.
2. Clique na aba "Settings" → menu lateral "Domains".
3. Clique em "Add".
4. Digite exatamente:  sigmavertice.org  (sem www) → "Add".
5. A Vercel vai dizer "Invalid Configuration" (normal — falta mudar DNS).
6. Clique em "Add" novamente e digite:  www.sigmavertice.org  → "Add".
7. Para cada um dos dois domínios (sigmavertice.org e www.sigmavertice.org),
   a Vercel vai te mostrar os VALORES DOS REGISTROS DNS que você precisa
   configurar lá no painel da SuperDomínios. Eles serão parecidos com:

   — Para o domínio RAIZ (sigmavertice.org, sem www):
        Tipo:       A
        Nome:       @
        Valor/IP:   76.76.21.21      (ou outro IP mostrado na Vercel)
        TTL:        300 (padrão)

   — Para o WWW (www.sigmavertice.org):
        Tipo:       CNAME
        Nome:       www
        Valor:      cname.vercel-dns.com    (OU o valor que a Vercel mostrar)
        TTL:        300

ANOTE esses dois valores exatamente como a Vercel mostrar.
Não copie os exemplos acima, use o que aparecer PARA VOCÊ na tela da Vercel.


======================================================================
PARTE 4/5 — ALTERAR O DNS NO PAINEL DA SUPERDOMÍNIOS
======================================================================

1. Abra: https://superdominios.com.br  → Entre na sua área do cliente.
2. Vá em "Meus Domínios" ou "Gerenciar Domínios" → abra sigmavertice.org.
3. Procure a opção "Gerenciar DNS", "Editar Zona DNS" ou "Registros DNS".
4. EXCLUA (ou edite) qualquer registro A ou CNAME EXISTENTE para "@" e "www"
   (tipo "estacionamento", "under construction", etc.) — se não houver, OK.
5. Adicione 2 novos REGISTROS DNS, exatamente como anotou da Vercel:

   REGISTRO 1 (DOMÍNIO RAIZ):
        Tipo:       A
        Host/Nome:  @   (ou deixar em branco, alguns painéis usam @)
        Aponta p/Valor: 76.76.21.21  (O QUE A VERCEL DISSER)
        TTL:        5 minutos / 300s  (ou mínimo possível)

   REGISTRO 2 (WWW):
        Tipo:       CNAME
        Host/Nome:  www
        Aponta p/Valor: cname.vercel-dns.com   (O QUE A VERCEL DISSER)
        TTL:        5 minutos / 300s

6. Salve / Aplicar as alterações.

7. SE a SuperDomínios te pedir "Nameservers", NÃO precisa mudar.
   Deixe os nameservers padrão da SuperDomínios. Só estamos editando os
   REGISTROS DNS A/CNAME dentro da zona.

8. A propagação de DNS pode demorar 2 minutos até 48h. Na prática,
   para domínios brasileiros, geralmente funciona em 10–30 minutos.


======================================================================
PARTE 5/5 — FINALIZAR DOMÍNIO NA VERCEL + HTTPS AUTOMÁTICO
======================================================================

1. Espere 10 minutos depois de mudar o DNS na SuperDomínios.
2. Volte em Vercel → Projeto → Settings → Domains.
3. Ao lado de "sigmavertice.org" vai aparecer um botão REFRESH.
   Clique. Quando a Vercel detectar o DNS correto, o status vai virar:
        ✅ Valid Configuration — verde
4. Faça o mesmo para "www.sigmavertice.org".
5. Clique no 3 pontinhos ao lado de "sigmavertice.org" → "Set as primary".
6. A Vercel ativa automaticamente HTTPS (SSL) com certificado Let's Encrypt.
   Aguarde mais 2–5 minutos.
7. TESTE FINAL: abra no navegador:
        https://sigmavertice.org
        https://www.sigmavertice.org

Se aparecer a tela de login AZUL/DOURADO do Sigma Vértice: SUCESSO! 🎉


======================================================================
PARTE 6/5 (OPCIONAL) — SE VOCÊ REALMENTE QUISER USAR A HOSPEDAGEM
           COMPARTILHADA LAUNCH DA SUPERDOMÍNIOS (EM VEZ DA VERCEL)
======================================================================

A hospedagem compartilhada da SuperDomínios (Plano Launch) é PHP + MySQL
padrão cPanel — NÃO roda Next.js 14 com SSR e API Routes nativamente.
Você só pode usar a hospedagem SuperDomínios se:

a) Alterar next.config.js para:  output: 'export'  (estático, sem SSR)
   — e refazer as rotas /api/* (auth/login, auth/mfa, etc.) para outra API.
   Isso PERDE as vantagens do Next SSR e reduz MUITO a segurança.

b) Ou contratar um plano VPS na SuperDomínios (paga mais) e instalar Node 20+
   + PM2 + Nginx manualmente.

Recomendação OFICIAL Sigma Vértice:
   ⭐⭐⭐⭐⭐  MANTER A ARQUITETURA VERCEL + SUPABASE + DNS SUPERDOMÍNIOS.
   É a combinação mais rápida, barata (grátis), segura e escalável
   para o seu Portal com dezenas a milhares de funcionários.
